후속 단계에서 결정할 항목: 일반 Database Property/Formula 문법과 대형 Dataset 권한; Calendar/Timeline의 시간대·Dependency; Snapshot 보존 정책과 Branch Merge UX; Burn Link의 소비 정의와 Bot Preview 처리; Public Page SEO/Domain; File Size/Storage 정책; Canvas 라이선스와 Node 모델; Integration Secret 관리; Desktop 배포·Global Shortcut; 일반 멤버 Multi-device Pairing; E2EE 도입 여부와 서버 기능 변경.
