# 제품 비전

Status: Accepted Alpha specification

No account. Your workspace.

회원가입 없이 문서를 작성하고 Page에 사람을 초대해 공동 작업한다. 인터넷이 끊겨도 이미 저장한 문서와 Task를 계속 편집한다. 개인 개발 프로젝트로 2–4주 내 검증 가능한 핵심 Alpha를 목표로 한다.

개발자 개인과 일반 개인 사용자가 대상이며 개인·팀 사용을 동등하게 다룬다. Notion의 단계적 대체가 장기 목표다. 빠른 기록 → 문서 정리 → 지식 연결 → 공동 작업이 대표 흐름이다.

Alpha는 Nested Pages, Markdown Block Editor, Local Search/Backlinks, Task Table/Board, 실시간 협업, Page 초대, Comments, Recovery, Quick Capture, Export/Import를 제공한다.

출시 완료는 실제 두 브라우저에서 공동 편집하고 Offline 변경을 병합한 뒤 새 기기에 복구할 수 있는 것으로 판단한다. 서버가 문서를 처리할 수 있는 Alpha이며 E2EE로 홍보하지 않는다.
