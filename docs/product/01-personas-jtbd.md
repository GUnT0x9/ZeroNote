# 사용자와 JTBD

Status: Accepted Alpha specification

## 개발자 개인

개발 중 떠오른 내용을 즉시 Inbox에 기록하고 기술 문서로 정리한다. Code Block, Keyboard Shortcut, Page 연결, Offline 편집이 중요하다. 성공: 다른 작업 흐름을 오래 끊지 않고 내용을 남기고 나중에 찾는다.

## 일반 개인 사용자

학습·기록·프로젝트 문서를 Nested Pages로 정리하고 연결한다. 복잡한 개발 도구 UI를 요구하지 않는다. 성공: 문서 제목과 본문 검색으로 필요한 기록을 찾고 연결된 문서로 이동한다.

## 소규모 공동 작업

계정 초대 대신 Page 초대를 받아 함께 문서를 편집하고 Task를 나눈다. 성공: Viewer는 읽고 Commenter는 의견을 남기며 Editor는 내용과 Task를 수정한다.

핵심 JTBD: 로그인 절차 없이 시작한다 / 끊긴 인터넷에서도 작업을 이어간다 / 문서와 작업을 연결한다 / 필요한 Page만 타인에게 제공한다 / 기기 변경 후 작업 공간을 되찾는다.
